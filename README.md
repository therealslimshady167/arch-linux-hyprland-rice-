# Arch Rice

My personal Arch Linux + Hyprland desktop setup.

## Included

- Hyprland configuration
- Hyprlock and Hyprpaper
- Waybar with custom scripts
- Kitty configuration
- Rofi theme
- Custom CAVA terminal visualizer
- GRUB theme
- Wallpapers
- Installation script

## Installation

Clone the repository, enter the directory, and run:

    chmod +x install.sh
    ./install.sh

The installer backs up existing Hyprland, Waybar, Kitty, Rofi, Wofi, and CAVA configurations before installing the rice.

## Notes

This setup is designed for my Arch Linux system and may require adjustments for different hardware or package configurations.

GRUB configuration files are not included; only the custom theme assets are provided.

GDM, Plymouth, Eww, and other unused components are intentionally excluded.
